# Video School — KGV Video Studio School

A one-page learning website that teaches the 9-stage AI short-video pipeline
(brief → concept → script → storyboard → animatic → build → QA → critics → delivery),
built around the BrewClub pilot with interactive tools: crew tabs, pipeline stepper,
Jev confidence slider, prompt workshop, gates quiz, glossary flashcards.

纯静态单页学习网站：9 阶段 AI 短视频制作流程教学（以 BrewClub 实战为例），含交互工具。

## Run locally / 本地预览

Open `index.html` in any browser. / 直接用浏览器打开 `index.html` 即可。

## Deploy / 部署

Static only — no build step. Push this folder to a GitHub repo, then import the
repo in Vercel (Framework Preset: Other). Done.

纯静态，无需构建。推送到 GitHub 后在 Vercel 里 Import 这个仓库即可上线。
