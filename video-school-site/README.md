# Video School — video-making learning site

A single self-contained static page (plus one poster image) that teaches how the
BrewClub pilot film was made with Muse AI, gstack, Jev and showtime — and now
embeds the finished film itself, published on YouTube:
https://youtube.com/shorts/htJBvKUL3WM

No build step. Deploy as-is on any static host (Vercel: Framework Preset "Other",
no build command, no output directory).
